Say you wished to forecast daily temperature. There are an infinite number of values which can be the temperature.

When the entity we wish to predict or extrapolate can take on a whole range of values, as in this example, we say that we have a regression problem.

One introductory form of regression is Linear Regression. In this section, we will explore Linear Regression, which is a core part of Machine Learning.

2.1Computing the Hypothesis

Continuing with our temperature forecasting example, say we wish to predict the temperature on a given day in a particular place in the world using the month of the year.

We will label the months as January-1, February-2, March-3, etc. Then, let h(x) be a function that computes the hypothesis, or prediction, of the temperature given the month number x.

Let’s say we know that h(x)=−x+70 (we will discuss how to find h(x) later). Then, we can calculate the (approximate) temperature on a given day.

Maybe I want to plan a party on April 1st and want to know what the weather will be like. April corresponds to 4, as it is the fourth month of the year. Then, our hypothesis becomes: h(x)=h(4)=−4+70=66 degrees. Similarly, I can find the (approximate) temperature on any given day if I know the month the day is in.

Unfortunately, I decide that knowing the month is not enough. I want to give my model more information so that it can make a more educated prediction.

Let us adjust our function h(x) to take in two inputs: the month (x1​) as well as the year of the given day we wish to predict (x2​).

Then, let’s say we know that our adjusted function is h(x1​,x2​)=−2x1​+0.001x2​+70. Then, we can calculate the temperature of a given day using the month and year that the day is in.

Let’s use our example of April 1st again. This time we must also know the year on which the party will occur. Let the party occur on April 1st, 2020. Then, x1​=4 and x2​=2020. Make sure you see why. Then, the temperature hypothesis is h(x1​,x2​)=h(4,2020)=−2(4)+0.001(2020)+70=−8+2.02+70=64.02 degrees. This is how we compute the Linear Regression hypothesis. Let us generalize this.

Say we are doing a regression problem in which we wish to predict or hypothesize some entity (temperature of a given day in the last case) given some inputs x1​,x2​,x3​,x4​,… These inputs are called features (or x-values) and what we wish to predict is called the label (or y-values).

Then, the objective of Machine Learning is to find a function that maps our features to our labels. This function is called the hypothesis function, as mentioned earlier.

When given a data set, we often wish to evaluate our model by using the given inputs to generate a hypothesis using our hypothesis function and comparing this prediction to the actual label of the entry in the data set. Our prediction is sometimes called the predicted value and the actual y-value recorded in the data set is called the observed value.

Linear regression is a means to an end to find a hypothesis function to map the input features to the output labels. In general, linear regression hypothesis functions look like the following: h(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​)=θ0​+θ1​x1​+θ3​x3​+θ4​x4​+…+θn​xn​, where x1​,x2​,⋯,xn​ are the input features, h is the hypothesis function, and θ0​,θ1​,⋯,θn​ are the parameters or weights.

In the previous example, h(x1​,x2​)=−2x1​+0.001x2​+70. Here, -2, 0.01, and 70 were the parameters, or weights. Notice that θ0​=70 in this example. The parameter θ0​ is always added in the hypothesis regardless of the value of any input. θ0​ is sometimes called the bias term. The output of the function h is sometimes called y^​ for shorthand.

Notice that if there were only one input x1​, then the hypothesis would be h(x1​)=θ0​+θ1​x1​. Taking θ0​ and θ1​ to be constants b and m, respectively, we get y^​=h(x1​)=b+mx1​ or y^​=mx1​+b. You may remember from your Algebra knowledge that this is just the equation of a line in 2 dimensions! In fact, a linear regression hypothesis which takes n features inputs is actually the equation of a line in n+1 dimensions! Hence, the name “Linear” Regression.

Remark (Another Perspective). Qualitatively, this is what Linear Regression is doing: Linear Regression takes each of the inputs, multiplies each by some number, takes the sum, and adds a constant. And ta-da! A hypothesis!

2.2Linear Regression Cost Function

The goal of Linear Regression (and any other type of regression) is to learn the hypothesis function for a data set by learning the values of the parameters.

We will go over how to do this, but first, we must talk about a way to evaluate the model. For Machine Learning problems, we use cost functions to evaluate our models. This cost function then becomes what we wish to optimize.

In linear regression, we use the Mean Squared Error (MSE) as our cost function.

For one example in our data set, this is how we would compute the cost function:

  1. Compute the hypothesis y^​ for the given example;

  2. If the observed value for the example is y, then the cost for this example is (y^​−y)2

Then, to evaluate the cost for the m examples in our data set, we simply take the average of all of the costs and divide by 2. Namely, the cost function, typically denoted J(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​), is: J(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​)=2m1​i=1∑m​(yi​−y^​i​)2, where yi​ and y^​i​ are the observed and predicted values for the ith example in the data set, respectively.

Remark. Don’t get too warped up in this technical definition of the cost function. Just understand what the cost function is meant to be used for and how to calculate the cost for one example in the data set.

Since the cost function measures the error of the predictions (Why?), we wish to minimize our cost. In this example, we wish to make θi​ coincide with the dot above, as it is the minimum. In a similar way, we would optimize all of our parameters. But how do we go about doing that?

We call the lines that were just drawn tangent lines because in the general vicinity of the given points, they only intersect the graph of the cost function at that point.

In the next parts, we will discuss exactly how to find the slopes of these lines for Machine Learning cost functions and functions in general.

For now, we examine the presented cases:

  1. The value of θi​ is more than the optimal value. Then, as we saw, the slope of the tangent line is positive and we wish to decrease our parameter value.

  2. The value of θi​ is less than the optimal value. Then, as we saw, the slope of the tangent line is negative and we wish to increase our parameter value.

Because of these two cases, it makes sense if we were to adjust the value of θi​ through doing the following: θi​:=θi​−αdθi​dJ​, where the := means that we replace θi​ with the value on the right, α is a constant, and dθi​dJ​ is the slope of the tangent line.

Notice that no matter where θi​ is with respect to the optimal value of θi​, we always make the parameter update in the correct manner using this method.

Remark. Make sure you understand how this parameter update satisfies both of the above cases before you move on!

This parameter update is not specific to Linear Regression. This is how parameters are updated for any type of Machine Learning model.

Remark. If this is your first time reading this, then do not worry if you do not understand why we use the seemingly arbitrary “slope of the tangent line.” Focus more on convincing yourself that this method will update the parameters correctly. As you will see, we use the slope of the tangent line simply because it is easy to find its value.

Remark (Alpha). Alpha (α) is a seemingly random constant that appears in the parameter update. Since it is defined to be positive, it does not affect the direction in which we adjust our parameters; rather, it controls the magnitude by which we make the adjustment. Too small of an α value and we make too small of a step in the direction to the optimal parameter value. Too large an α value and we make too large of a step in the direction to the optimal parameter value and we “overshoot” the minimum. If we overshoot enough, our parameter value can diverge. Because of these effects, α is called the learning rate of a Machine Learning model.

2.4Gradient Descent

Now, it is time to put our ideas together in a concrete fashion. In this section, we introduce the idea of Gradient Descent and explain how it is used in finding the parameters for a Machine Learning model. These learned parameters can then be used to create the hypothesis function, which is the goal of Machine Learning.

Gradient Descent is described very generally and briefly by the following steps:

  1. Initialize Parameters: Parameters have to start somewhere! Sometimes, we initialize them to be 0, and other times at random. This depends on the parameter type and the model we are using.

  2. Compute the Cost Function Using the Current Hypothesis Function: We use our existing hypothesis function h to compute our hypothesis y^​. Then, we use y^​ and the observed values y to compute the cost function J.

  3. Parameter Update: We compute the slope of the tangent line to the cost function and use this to update our parameters and make our hypothesis function just a bit better as talked about in the last section. Note that we can often update the parameters without ever computing the cost, but the cost is a helpful indicator that your model is working as intended.

  4. Repeat!: We repeat steps 2 and 3 over, and over, and over…until our cost is low enough that we are happy with it.

This above process is the core of most all Machine Learning algorithms, so make sure you know it by heart!

For Linear Regression, we initialize all of our parameters to be 0. We know how to compute the cost, and we know about the parameter update except for the slope of the tangent line part. We will cover this specific detail later. For now, make sure you understand how Machine Learning algorithms are trained (at a high level).
