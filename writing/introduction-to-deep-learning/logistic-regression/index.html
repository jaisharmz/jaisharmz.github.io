Logistic Regression is also one of the core parts of Neural Networks. Arguably, Neural Networks is just a series of Logistic Regression Functions. In this section, we discuss Logistic Regression as an extension of Linear Regression.

3.1Logistic Regression Hypothesis

Once you understand what Linear Regression is doing, the Logistic Regression hypothesis function is quite simple to understand.

Let our hypothesis h(x1,x2,⋯ ,xn,θ0,θ1,θ2,⋯ ,θn)h(x_1,x_2,\cdots,x_n,\theta_0,\theta_1,\theta_2,\cdots,\theta_n)h(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​) be defined as the following: h(x1,x2,⋯ ,xn,θ0,θ1,θ2,⋯ ,θn)=σ(g(x1,x2,⋯ ,xn,θ0,θ1,θ2,⋯ ,θn)),h(x_1,x_2,\cdots,x_n,\theta_0,\theta_1,\theta_2,\cdots,\theta_n)=\sigma(g(x_1,x_2,\cdots,x_n,\theta_0,\theta_1,\theta_2,\cdots,\theta_n)),h(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​)=σ(g(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​)), where g(x1,x2,⋯ ,xn,θ0,θ1,θ2,⋯ ,θn)g(x_1,x_2,\cdots,x_n,\theta_0,\theta_1,\theta_2,\cdots,\theta_n)g(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​) is a Linear Regression hypothesis function and σ(x)=11+e−x\sigma(x)=\frac{1}{1+e^{-x}}σ(x)=1+e−x1​ for any real number xxx.

Here is the graph of σ(x)\sigma(x)σ(x):

What is the hypothesis function doing? It is taking the output of some Linear Regression function and feeding it into the sigmoid function σ(x)\sigma(x)σ(x), a function which outputs a number between 0 and 1.

0 and 1? That sounds like the range we use for probability. In fact, that is exactly what it is! Essentially, the Logistic Regression hypothesis function maps its inputs to a probability. Now why would this be useful?

3.2Applications of Logistic Regression

In Linear Regression, our output can take on a near infinite number of values. We call this a continuous output. Logistic Regression, however, is more useful when our output can only take on a finite number of values. We call this a discrete output.

Here are some questions/problems that could be aided using Logistic Regression:

  • Will it rain tomorrow or not? Here, there are two options: 1) Yes, it will rain, and 2) No, it will not rain.

  • Is a given email spam or not? This also has two options.

  • Is a given product that was produced in a factory defective? Again, there are two alternatives.

  • Identify hand-written digit. This problem has ten options: 0,1,2,⋯ ,90,1,2,\cdots,90,1,2,⋯,9

For the first three, we can train a Logistic Regression model to find the probability for each event happening. For the last one, however, we will need to train 10 different models. Namely, we will need to train one model to output the probability that the digit is 0, one model to output the probability that the digit is 1, and so on. To determine what digit a given digit is, we will trust the model with the highest probability.

Remark. For this last example, Neural Networks can output more than one probability, which means that we can train just one model instead of 10.

After we find the probabilities, we can decide our final prediction. If y^≥0.5\hat{y}\geq 0.5y^​≥0.5, we output “1,” meaning that we believe that it will rain, or the email is spam, or the given product is defective, following the previous examples. If y^<0.5\hat{y}< 0.5y^​<0.5, we output “0,” meaning that we believe that it will not rain, or the email is not spam, or the given product is not defective.

Now, how do we train our model? For that, we will need to define a cost function for Logistic Regression.

Remark. The name “Logistic Regression” is somewhat misleading. Logistic Regression is actually a kind of classification, not regression. This is because we have a discrete output range instead of a continuous one. In general, classification refers to identifying and “classifying” and example based on its input features.

3.3Logistic Regression Cost Function

For Logistic Regression, we use the same algorithm as the one for Linear Regression: Gradient Descent. We initialize all our parameters to 0, but how do we measure the cost? Do we use MSE (which we used for Linear Regression) or something else?

It turns out that MSE is no longer a desirable cost function for Logistic Regression. In Linear Regression, we were measuring the “distance” between our predictions and the observed values. We could do this because our output was continuous. However. It does not make sense to do the same thing anymore since the output will always be between 0 and 1.

So, how do we measure the cost? If yyy is the observed value (which is always either 0 or 1) and if y^\hat{y}y^​ is the prediction, then the cost for one example is: −ylog⁡y^−(1−y)log⁡(1−y^).-y\log{\hat{y}}-(1-y)\log{(1-\hat{y})}.−ylogy^​−(1−y)log(1−y^​). Note that the “log” function here is not in base 10; it is in base eee, so this is actually the natural logarithm function being used. Also notice that both terms are negative.

To find the cost over the whole data set, we simply take the average like before. Then, our cost function

J(x1,x2,⋯ ,xn,θ0,θ1,θ2,⋯ ,θn)J(x_1,x_2,\cdots,x_n,\theta_0,\theta_1,\theta_2,\cdots,\theta_n)J(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​) is: J(x1,x2,⋯ ,xn,θ0,θ1,θ2,⋯ ,θn)=−1m∑i=1mylog⁡y^+(1−y)log⁡(1−y^).J(x_1,x_2,\cdots,x_n,\theta_0,\theta_1,\theta_2,\cdots,\theta_n)=-\frac{1}{m}\sum_{i=1}^m y\log{\hat{y}}+(1-y)\log{(1-\hat{y})}.J(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​)=−m1​i=1∑m​ylogy^​+(1−y)log(1−y^​). Again, expanding the cost function to the whole data set is a trivial detail, so just focus on understanding the cost function with respect to one example. This cost function is called the Binary Cross Entropy Loss function. For short, we will call it the Cross Entropy cost function in this text.

So now that we have talked about the definition of the cost function, why does it work? To explain how the Cross Entropy cost function satisfies our needs, we consider two cases. Note that we will only be looking at the cost function with respect to one example, but a similar argument holds for why the cost function works with respect to the whole data set.

The observed output yyy can only take on two values: 0 and 1. There is no in between because we are considering discrete outputs. Here are the cases for each of the values of yyy:

Case 1: y=0y=0y=0 If y=0y=0y=0, then the cost for one example is: −0log⁡y^−(1−0)log⁡(1−y^)=−log⁡(1−y^).-0\log{\hat{y}}-(1-0)\log{(1-\hat{y})}=-\log{(1-\hat{y})}.−0logy^​−(1−0)log(1−y^​)=−log(1−y^​). Now, the cost function has reduced to one term. Since we wish to minimize the cost, we wish to maximize log⁡(1−y^)\log{(1-\hat{y})}log(1−y^​) (because of the negative sign. To maximize log⁡(1−y^)\log{(1-\hat{y})}log(1−y^​), we must maximize 1−y^1-\hat{y}1−y^​. To do this, we must minimize y^\hat{y}y^​. (Do you see why?) Since 0 is the minimum value for y^\hat{y}y^​ (because it is an output of the sigmoid function), we our global minimum occurs when y^=0\hat{y}=0y^​=0. Notice that in this case, we assumed y=0y=0y=0, so our global minimum occurs when these two match, which means that the Cross Entropy cost function works in this case.

Case 2: y=1y=1y=1 If y=1y=1y=1, then a similar argument holds. The cost function becomes: −1log⁡y^−(1−1)log⁡(1−y^)=−log⁡y^.-1\log{\hat{y}}-(1-1)\log{(1-\hat{y})}=-\log{\hat{y}}.−1logy^​−(1−1)log(1−y^​)=−logy^​. This time, the other term has been canceled out! We now wish to minimize −log⁡y^-\log{\hat{y}}−logy^​, which means that we want to maximize log⁡y^\log{\hat{y}}logy^​, like before. In order to maximize this, we must maximize y^\hat{y}y^​. However, the highest possible value for y^\hat{y}y^​ is 1, as mentioned in the previous case. Therefore, the global minimum occurs when y^=1\hat{y}=1y^​=1. Notice that we assumed in this case that y=1y=1y=1, so the Cross Entropy Cost Function does a good job of giving a low cost when the predicted value and the observed values match as well.

Make sure you understand this argument because we use the same cost function for Neural Networks!
