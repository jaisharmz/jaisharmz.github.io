7.1Linear Regression Parameter Update Derivation

Since the section on Linear Algebra, we have changed the way we represent our input xxx values, output yyy values, and our parameters. First, let’s catch up on the notation and cost function.

7.1.1Notation and Cost Function

Let X be a matrix of shape (n,m)(n,m)(n,m) that represents the inputs to the Linear Regression model, where nnn is the number of features and mmm is the number of examples in the data set. This means that the examples in our data set are in the columns, not rows.

Let Xi,j\textbf{X}_{i,j}Xi,j​ signify the element in the iiith row and jjjth column of X\textbf{X}X. Additionally, let Xi,:\textbf{X}_{i,:}Xi,:​ signify all of the elements in the iiith row of X. Similarly, let X:,j\textbf{X}_{:,j}X:,j​ signify all of the elements in the jjjth column of X.

For Linear Regression, recall the hypothesis function we used before: h(x1,x2,⋯ ,xn,θ0,θ1,θ2,⋯ ,θn)=θ0+θ1x1+θ3x3+θ4x4+…+θnxn.(1)h(x_1,x_2,\cdots,x_n,\theta_0,\theta_1,\theta_2,\cdots,\theta_n)=\theta_0+\theta_1x_1+\theta_3x_3+\theta_4x_4+\ldots+\theta_nx_n.\tag{1}h(x1​,x2​,⋯,xn​,θ0​,θ1​,θ2​,⋯,θn​)=θ0​+θ1​x1​+θ3​x3​+θ4​x4​+…+θn​xn​.(1) For Deep Learning, we will define a new but intuitive operation where we add a matrix and a scalar. The value A+b\textbf{A}+bA+b, where A is a matrix and bbb is a scalar, is a matrix in which every element of A is increased by bbb. This is called broadcasting in the computer programming language Python. (By this definition, the resulting matrix has the same shape as A.)

Let b=θ0b=\theta_0b=θ0​ and W=(θ1θ2θ3⋯θn)\textbf{W}= \begin{pmatrix} \theta_1 & \theta_2 & \theta_3 & \cdots & \theta_n \end{pmatrix}W=(θ1​​θ2​​θ3​​⋯​θn​​).

Then, notice that we can rewrite the hypothesis function shown in equation (1) through the following: Y^=h(X,b,W)=W×X+b.\hat{\textbf{Y}}=h(\textbf{X},b,\textbf{W})=\textbf{W}\times \textbf{X} + b.Y^=h(X,b,W)=W×X+b. To be sure that this is correct, let’s check matrix dimensions. The left side is the final hypothesis, and since examples are in columns, h(X,b,W)h(\textbf{X},b,\textbf{W})h(X,b,W) should be a row vector with mmm entries (one entry for each of the mmm examples). Therefore, the shape is (1,m)(1,m)(1,m).

The right side is matrix multiplication. W has shape (1,n)(1,n)(1,n) and X has shape (n,m)(n,m)(n,m). When we multiply these, we should get a matrix with dimensions (1,m)(1,m)(1,m). Because the “+b+b+b” does not change the matrix dimensions, we have confirmed that the left side and right side have the same matrix shapes.

7.1.2Derivation

Earlier, we mentioned that we needed to find the “slope of the tangent line.” In this section, we will specify what this means and how to derive it.

By the “slope of the tangent line,” we mean the derivative of the cost function with respect to some parameter θ\thetaθ, or dJdθ\diff{J}{\theta}dθdJ​. In this case, θ=W\theta=\textbf{W}θ=W or θ=b\theta=bθ=b. We will handle each case separately.

We know that these are the derivatives that we are trying to find because we are trying to find the slope of the tangent line to the cost function JJJ where the parameter θ\thetaθ is the independent variable of this graph.

Do you see why we use the derivative that we do?

Now that we have outlined our problem, we can try to solve it.

Deriving dJdW\diff{J}{\textbf{W}}dWdJ​ We start by finding dJdW\diff{J}{\textbf{W}}dWdJ​. (Note that we will refer to functions by their name and leave out the parameters here. For example, J(X,b,W)J(\textbf{X},b,\textbf{W})J(X,b,W) becomes JJJ.)

We start with the cost function: J=12m(Y−Y^)2.J=\frac{1}{2m} (\textbf{Y}-\hat{\textbf{Y}})^2.J=2m1​(Y−Y^)2. Then, we take the derivative of both sides with respect to W. Remember that Y^\hat{\textbf{Y}}Y^ is a function of W and Y is not. Therefore, we can treat Y as a constant with respect to W, while we must use the Chain Rule for derivatives for Y^\hat{\textbf{Y}}Y^. Then, the derivative of this equation with respect to W becomes: dJdW=12m⋅2(Y−Y^)×[0−dY^dW]=1m⋅(Y^−Y)×dY^dW.\diff{J}{\textbf{W}}=\frac{1}{2m}\cdot 2(\textbf{Y}-\hat{\textbf{Y}})\times \left[0-\diff{\hat{\textbf{Y}}}{\textbf{W}}\right]=\frac{1}{m}\cdot (\hat{\textbf{Y}}-\textbf{Y})\times \diff{\hat{\textbf{Y}}}{\textbf{W}}.dWdJ​=2m1​⋅2(Y−Y^)×[0−dWdY^​]=m1​⋅(Y^−Y)×dWdY^​. (Now you know why the cost function had the coefficient 12m\frac{1}{2m}2m1​ instead of 1m\frac{1}{m}m1​. It cancels nicely when you take the derivative.) Notice that we use matrix multiplication instead of regular multiplication because we are dealing with matrices and not scalars. Now, we have to find out what dY^dW\diff{\hat{\textbf{Y}}}{W}dWdY^​ is.

We know by the hypothesis function that: Y^=W×X+b.\hat{\textbf{Y}}=\textbf{W}\times \textbf{X} + b.Y^=W×X+b. Taking the derivative of both sides with respect to W, we get: dY^dW=X.\diff{\hat{\textbf{Y}}}{\textbf{W}}=\textbf{X}.dWdY^​=X. Remember, bbb is a constant with respect to W. We can plug this back into the expression we got earlier for dJdW\diff{J}{\textbf{W}}dWdJ​: dJdW=1m⋅(Y^−Y)×X.\diff{J}{\textbf{W}}=\frac{1}{m}\cdot (\hat{\textbf{Y}}-\textbf{Y})\times \textbf{X}.dWdJ​=m1​⋅(Y^−Y)×X. Now, there is one caveat with how we have written this derivative expression. We have the general idea down, but we have to examine the shapes of our matrices to make sure. We will omit the scalars here because scalar multiplication does not affect the dimensions of the matrix.

The matrix Y^−Y\hat{\textbf{Y}}-\textbf{Y}Y^−Y has shape (1,m)(1,m)(1,m) and the matrix X has shape (n,m)(n,m)(n,m). Therefore, we cannot do matrix multiplication the way we have written it above.

Our final goal is to get dJdW\diff{J}{\textbf{W}}dWdJ​. Since we want each element of our derivative to correspond to a value in W, dJdW\diff{J}{\textbf{W}}dWdJ​ and W must have the same shape. Both must have dimensions (1,n)(1,n)(1,n). Notice that we can simply transpose X to get the desired dimensions. Specifically, the derivative becomes: dJdW=1m⋅(Y^−Y)×XT.\diff{J}{\textbf{W}}=\frac{1}{m}\cdot (\hat{\textbf{Y}}-\textbf{Y})\times \textbf{X}^T.dWdJ​=m1​⋅(Y^−Y)×XT. We have found dJdW\diff{J}{\textbf{W}}dWdJ​. What about dJdb\diff{J}{b}dbdJ​? We do this in the same way: we take the derivative of the cost function with respect bbb: dJdb=12m⋅2(Y−Y^)×[0−dY^db]=1m⋅(Y^−Y)⋅dY^db.\diff{J}{b}=\frac{1}{2m}\cdot 2(\textbf{Y}-\hat{\textbf{Y}})\times \left[0-\diff{\hat{\textbf{Y}}}{b}\right]=\frac{1}{m}\cdot (\hat{\textbf{Y}}-\textbf{Y})\cdot \diff{\hat{\textbf{Y}}}{b}.dbdJ​=2m1​⋅2(Y−Y^)×[0−dbdY^​]=m1​⋅(Y^−Y)⋅dbdY^​. Just like last time, we use the Chain Rule for derivatives. Now, we find dY^db\diff{\hat{\textbf{Y}}}{b}dbdY^​ by taking the derivative of the hypothesis function with respect to bbb: dY^db=1.\diff{\hat{\textbf{Y}}}{b}=1.dbdY^​=1. Remember, W and X are constants with respect to bbb, so their derivative is 0. Then, dJdb\diff{J}{b}dbdJ​ becomes: dJdb=1m⋅(Y^−Y)⋅1=1m⋅(Y^−Y).\diff{J}{b}=\frac{1}{m}\cdot (\hat{\textbf{Y}}-\textbf{Y})\cdot 1=\frac{1}{m}\cdot (\hat{\textbf{Y}}-\textbf{Y}).dbdJ​=m1​⋅(Y^−Y)⋅1=m1​⋅(Y^−Y). Again, there is a small caveat here: Y^−Y\hat{\textbf{Y}}-\textbf{Y}Y^−Y is matrix with shape (1,m)(1,m)(1,m) and dJdb\diff{J}{b}dbdJ​ has to be a scalar. To combat this problem, we simply take the sum of all of the elements in Y^−Y\hat{\textbf{Y}}-\textbf{Y}Y^−Y. When we multiply by 1m\frac{1}{m}m1​, we take the average of all of these elements. Using this logic, dJdb=1m⋅sum(Y^−Y).\diff{J}{b}=\frac{1}{m}\cdot \text{sum}(\hat{\textbf{Y}}-\textbf{Y}).dbdJ​=m1​⋅sum(Y^−Y). We now have dJdW\diff{J}{\textbf{W}}dWdJ​ and dJdb\diff{J}{b}dbdJ​.

Remember how we use these in the parameter update for W and bbb. This is how we update W: W:=W−α⋅dJdW.W:=W-\alpha\cdot \diff{J}{\textbf{W}}.W:=W−α⋅dWdJ​. Similarly, this is how we update bbb: b:=b−α⋅dJdb.b:=b-\alpha\cdot \diff{J}{b}.b:=b−α⋅dbdJ​.

7.1.3Putting it all together

In this section, we will review some material we went over in the Introduction section and see how it fits together with the parameter update we just derived. Specifically, we will look at Gradient Descent.

Gradient Descent

  1. Initialize all elements of W and bbb to 0 as setup for Gradient Descent1.

  2. Compute hypothesis function using existing values of W and bbb: Y^=h(X,b,W)=W×X+b.\hat{\textbf{Y}}=h(\textbf{X},b,\textbf{W})=\textbf{W}\times \textbf{X} + b.Y^=h(X,b,W)=W×X+b.

  3. Compute the cost function J(X,b,W)J(\textbf{X},b,\textbf{W})J(X,b,W): J(X,b,W)=12m(Y−Y^)2.J(\textbf{X},b,\textbf{W})=\frac{1}{2m} (\textbf{Y}-\hat{\textbf{Y}})^2.J(X,b,W)=2m1​(Y−Y^)2.

  4. Compute derivatives dJdW\diff{J}{\textbf{W}}dWdJ​ and dJdb\diff{J}{b}dbdJ​: dJdW=1m⋅(Y^−Y)×XTdJdb=1m⋅sum(Y^−Y)\begin{align*} \diff{J}{\textbf{W}}&=\frac{1}{m}\cdot (\hat{\textbf{Y}}-\textbf{Y})\times \textbf{X}^T\\ \diff{J}{b}&=\frac{1}{m}\cdot \text{sum}(\hat{\textbf{Y}}-\textbf{Y})\\ \end{align*}dWdJ​dbdJ​​=m1​⋅(Y^−Y)×XT=m1​⋅sum(Y^−Y)​

  5. Perform parameter update for W and bbb: W:=W−α⋅dJdWb:=b−α⋅dJdb\begin{align*} W:=W-\alpha\cdot \diff{J}{\textbf{W}}\\ b:=b-\alpha\cdot \diff{J}{b}\\ \end{align*}W:=W−α⋅dWdJ​b:=b−α⋅dbdJ​​

  6. Steps 2, 3, 4, and 5 were one step of Gradient Descent. Repeat steps 2, 3, 4, and 5 until the cost function JJJ has a sufficiently low value (or until it does not change much on each step of Gradient Descent).

Using this process, we can train a simple Linear Regression model. To make predictions, we can simply compute the hypothesis function: Y^=h(X,b,W)=W×X+b,\hat{\textbf{Y}}=h(\textbf{X},b,\textbf{W})=\textbf{W}\times \textbf{X} + b,Y^=h(X,b,W)=W×X+b, where W and bbb are our trained parameters and X is the input on which we are trying to make a prediction.

7.2Logistic Regression Parameter Update Derivation

We will now move onto the parameter update for Logistic Regression. This derivation will have striking similarities to the derivation in the last section.

Before we get to the derivation, let’s vectorize the cost function and hypothesis function.

7.2.1Notation and Cost Function

Let X, mmm, and nnn be defined as they were in the last section.

7.3Neural Networks Parameter Update Derivation

Finally, we will look at the parameter update for Neural Networks. This parameter update is special because the structure of the Neural Network can vary. (By contrast, the last two models we looked at have the same structure.)

We will instead attack this problem in a different way. Instead of finding the guaranteed formula for every parameter in the Neural Network, we will ”split the problem up.”

To do this, we will compute:

  1. Parameter update for the last layer variables

  2. Parameter update for a layer given the parameter update values from the next layer

Because we use the next layer’s parameter updates to find the parameter updates for some layer we call this method backpropagation.

Let the activation units of the next layer be ala_lal​ and let the activation units of the previous layer be al−1a_{l-1}al−1​. Let the weights of this layer be W and bbb. Additionally, let the outputs from applying the weights (and before the activation is applied) be zlz_lzl​. Let the corresponding outputs for the previous layer be zl−1z_{l-1}zl−1​. Finally, let the activation function which is applied to zlz_lzl​ to find ala_lal​ be g(x)g(x)g(x). 7.3.1Putting Backpropagation Together

In this section, we will go over how to put backpropagation together. Here are the major steps of the backpropagation algorithm:

  1. Find dJdy^\diff{J}{\hat{y}}dy^​dJ​. This will depend on the cost function being used by the network developer.

  2. Use the equations derived in the previous section to find the derivative of JJJ with respect to each of the parameters of the last layer as well as the activation units of the previous layer.

  3. Continue working your way back through the layers of the neural network, each time using the derivative of JJJ with respect to the activation units of the next layer to find the derivative of JJJ with respect to the parameters and activation units of the previous layer.

  4. Perform the parameter update on all parameters.

For the last item, remember that only the W’s and bbb’s are parameters, and we only find the derivative of JJJ with respect to the ala_lal​’s to work our way back through the network. In other words, do not try to update the ala_lal​’s.

The parameter update of parameter ppp is as follows: p:=p−α⋅dJdp.p:=p-\alpha\cdot \diff{J}{p}.p:=p−α⋅dpdJ​. Notice how this is exactly the same as all other parameter updates we have seen.

With that, we have completed our exploration of backpropagation in Neural Networks.
