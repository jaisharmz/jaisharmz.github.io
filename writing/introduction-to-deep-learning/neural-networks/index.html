4.1Neural Networks

Now that we have seen an introduction to Linear Regression and Logistic Regression, we are ready to put these together to look at a Neural Network.

4.1.1Neural Network Hypothesis

As mentioned earlier, Neural Networks are just stacked Logistic Regression hypotheses. Let’s look at an example of a computation of the hypothesis, or a forward pass.

Consider the following image:

In a Neural Network, we have input features x1,x2,⋯ ,xnx_1,x_2,\cdots,x_nx1​,x2​,⋯,xn​ as before, but computing the hypothesis is a little more work.

Before we go to our example, a bit of vocabulary: the input layer is a list of the input features x1,x2,⋯ ,xnx_1,x_2,\cdots,x_nx1​,x2​,⋯,xn​ and the output layer is a list of the predicted outputs y^\hat{y}y^​. Every “layer” in between is called a hidden layer. Notice that all of the hidden layer entries have a (1) as a superscript. This is because they are all in the first hidden layer. If there were more hidden layers, we would assign the superscripts accordingly. The subscript just corresponds to the entry in the layer as always. We will now go over how each of these “layers” work together to give us our hypothesis.

To be more concrete, let us use a Neural Network with real number inputs. We will use predetermined parameters for now, but we will discuss how to find the value of these parameters later.

In the above diagram, let x1=2x_1=2x1​=2, x2=5x_2=5x2​=5, and x3=6x_3=6x3​=6 be our input features which we put into the Input Layer. Then, each of a1(1)a_1^{(1)}a1(1)​, a2(1)a_2^{(1)}a2(1)​, and a3(1)a_3^{(1)}a3(1)​ are calculated as the output of some logistic regression hypothesis function. Here, each of the terms of the form θj(1)[i]\theta^{(1)[i]}_jθj(1)[i]​ are constants. When we run our Neural Network using the Gradient Descent algorithm, we do not know the values of these constants; instead, we learn them through the process of Gradient Descent. Hence, these terms in the form θj(1)[i]\theta^{(1)[i]}_jθj(1)[i]​ are our parameters.

Notice that the index iii corresponds to the fact that we are using the parameter to calculate ai(1)a_i^{(1)}ai(1)​ and the jjj here corresponds to the parameter number in each hypothesis function (i.e. the 0th parameter, the 1st parameter, etc.). Finally, notice that we use (1) in the superscript to indicate that we are using the parameters to compute the entries in Hidden Layer 1, or the 1st layer.

Remark (Layer Numbering). The layer of the Neural Network that is fed in, or the “first layer,” is often called the Input Layer, as mentioned earlier. However, the next layer after this is often called Layer 1, or the 1st Layer, because this is the first layer that we compute. Each subsequent layer after that is numbered accordingly, even the Output Layer. So, in this example, Hidden Layer 1 would be the 1st Layer, and the Output Layer would be the 2nd Layer.

Do not pay too much attention to the notation here as it is not all too important. We will find a way to express this in a simpler way later. For now, focus on how each of the entries in Hidden Layer 1 are computed.

Once you understand the example above, the following are a few items to take note of.

First, notice how Neural Networks can output multiple numbers, making them immensely more powerful than Logistic Regression. Recall that if we wish to classify our output using Logistic Regression into more than two classes, or Multi-class Classification, then we must train as many Logistic Regression hypothesis functions as there are classes. However, we can do all of this using just one Neural Network since Neural Networks can output multiple probabilities in one hypothesis function, each corresponding to the probability that the Input Layer matches each one of the classes. Then, we can decide which class the Input Layer belongs to by trusting the highest probability output (as we had done earlier). Make sure you see why this works as it is extremely important for more complex Neural Network types.

Second, notice that we had 3 entries in our only Hidden Layer. In general, we can have as many entries in as many Hidden Layers as possible. The number of entries can even vary from Hidden Layer to Hidden Layer. These choices are handpicked and are something to be experimented with. The only layers that cannot be experimented with are the Input Layer and the Output Layer. These depend on the number of input features and the number of Output Labels (or classes), respectively. In general, a Neural Network is built up in the following way: Input Layer→Hidden Layer 1→Hidden Layer 2→…→Hidden Layer L−1→Output Layer.\text{Input Layer}\to\text{Hidden Layer 1}\to\text{Hidden Layer 2}\to\ldots\to\text{Hidden Layer }L-1\to\text{Output Layer}.Input Layer→Hidden Layer 1→Hidden Layer 2→…→Hidden Layer L−1→Output Layer. The entries in the Input Layer are given in the data set, and the entries in every other layer are calculated in the same way as the previous example: many, many stacked Logistic Regression hypothesis functions.

Finally, we train a Neural Network and find the optimal value for its parameters through Gradient Descent. Note that for Neural Networks, we also use the Cross Entropy cost function to measure the model error. To initialize our parameters, we initialize the bias terms (the terms in the form θ0(l)[i]\theta_0^{(l)[i]}θ0(l)[i]​) of the Neural Network to be 0, like normal. For the rest of the parameters, however, we initialize them to be random real numbers usually in the range of [−1,1][-1,1][−1,1] (this includes decimals).

Why don’t we just initialize them to be 0 like before? Well, as we will learn, if the parameters are all 0 (or the same number), then they will get the same parameter update, meaning that they will yet again be the same number. Through the course of training the Neural Network, the parameters always stay the same. It can be shown that when the parameters are all the same for each layer, then all of the entries in all of the Hidden Layers are the same, and therefore the resulting hypothesis function is no better than a Logistic Regression hypothesis function. Do you see why? We must initialize these parameters at random in order to “break symmetry.”
