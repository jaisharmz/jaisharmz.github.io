In this part, we will focus on deriving the value of the “slope of the tangent line” in order to perform the parameter update for each algorithm talked about in the last part. In order to do this, however, we must learn about the elementary basics of Linear Algebra and Calculus, two very important branches of math in Deep Learning.

Linear Algebra, in an oversimplified context, is the study of lines in multiple dimensions. In this section, we learn the fundamentals of this subject, which is crucial to the topic of Machine Learning.

Note that while Linear Algebra has vast Geometric implications, we will be viewing it from a more Algebraic point of view with respect to Machine Learning.

5.1A Vector

In this section, we introduce the notion of a vector.

Definition (Vector). A vector is a list of numbers in a row or column. The number of entries in a vector is called the length of a vector. We often denote a vector with a lowercase letter with an arrow on it like this: v.

Before we see some examples, let’s give name to a more familiar quantity.

Definition (Scalar). A scalar is a real number.

Let’s see some examples of vectors: ​12.30−25−1234.56π/33​​​,​100​​,(0​0​0​0​). Notice that we put parentheses around our vectors. While vectors can be rows or columns, we will focus more on column vectors.

Scalars are something we are more familiar with. Here are some examples: π,23,0,−2.5,2​. We can change a column vector into a row vector (and visa versa) through transposing it. We simply write the numbers in the same order but different orientation. Specifically, we would transpose the vector (1​2​3​4​) to ​1234​​. The transpose of this resulting vector would just be the vector we started with. Do you see why?

We can do scalar multiplication by a vector by multiplying the scalar by each of the elements of the vector. For example, −2⋅​1234​​=​−2−4−6−8​​. We can also add two vectors by adding their corresponding elements. For example, ​1234​​+​5678​​=​681012​​. Note that this only works if the two vectors have the same length. We can subtract two vectors in the same way.

In addition to these elementary operations, there is a special operation which we can do when given a row vector and a column vector of the same length. This operation is called the dot product. We denote the dot product with a “⋅“ just like with multiplication of scalars.

Remark. Technically, the dot product can be done with two column vectors (or two row vectors), but we put this restriction to make matrix multiplication easier to understand. If you do not understand this remark, just ignore it.

To compute the dot product of a row vector and a column vector, we multiply the corresponding elements of the two vectors and we add our results. Take this example: (1​2​3​4​)⋅​5678​​=(1)(5)+(2)(6)+(3)(7)+(4)(8)=5+12+21+32=70. Note that the row vector must always come first. Also note that the dot product of two vectors is just a scalar! Let’s now expand the idea of vectors.

5.2A Matrix

A matrix is just an extension of a vector.

Definition (Matrix). A matrix is a series of column vectors stacked together from left to right. We denote a matrix with an uppercase bold letter like this: A.

Let’s see some examples of matrices: (13​24​),​100​010​001​​,(15​26​37​48​). Vectors are actually just special types of matrices. We can do matrix addition and subtraction similar to what we did with vectors. For example, (13​24​)+(57​68​)=(610​812​), and similarly for subtraction. Notice that we can only add two matrices if their “shapes” are the same. We will talk more about this in a bit. But first: we can also do scalar multiplication by a matrix. See this example: −2⋅(13​24​)=(−2−6​−4−8​). The shape of a matrix is written in a coordinate pair like so: (number of rows in matrix,number of columns in matrix). So, the shape of the matrix (13​24​) is (2,2) since there are 2 rows and 2 columns in this matrix, and the shape of the matrix ​135​246​​ is (3,2) since there are 3 rows and 2 columns in this matrix. In matrix A, we refer to the element in the ith row and jth column as Ai,j​.

We can also transpose matrices like we do with vectors. Let A be a matrix with shape, or dimensions, of (p,q). Define AT, the transpose of A, such that Ai,j​=Aj,iT​. Essentially, we mirror the elements of A over the diagonal going from the top left of the matrix to the lower right. For example: (14​25​36​)T=​123​456​​.

Finally, we wonder if there is an operation similar to the dot product for matrices. There is, and it is called matrix multiplication, and we denote it with a “×“ just like with multiplication of scalars. First, we start with matrix multiplication by a vector. To “multiply” a matrix and a vector, we compute the dot product of each row of the matrix (which is a vector) and the vector. We then put our results into a vector. For example, (13​24​)×(56​)=((1)(5)+(2)(6)(3)(5)+(4)(6)​)=(1739​). Make sure you understand this example. To do matrix by matrix multiplication, we multiply the first matrix by the first column of the second matrix (which is a column vector). The result is the first column of the matrix which is our answer. Then, we multiply the first matrix by the second column of the second matrix. This becomes the second column of our answer, and so on. In general, we multiply the first matrix by the ith column of the second matrix to get the ith column of our answer. Watch the next example closely to see how this works: (13​24​)×(57​68​)=((1)(5)+(2)(7)(3)(5)+(4)(7)​(1)(6)+(2)(8)(3)(6)+(4)(8)​)=(1943​2250​). Again, make sure you understand this example. Looking back at our problem, we see another way to think about matrix multiplication: if C is the resulting matrix, then we can calculate Ci,j​ by taking the dot product of the ith row of the first matrix and the jth column of the second matrix.

Furthermore, in order to take the individual dot products, the first matrix must have as many columns as the second matrix has rows. Therefore, if we wish to compute A×B and A has shape (m,n) and B has shape (p,q), then we must have that n=p. Furthermore, since the element Ci,j​ in the product C is found by taking the dot product of the ith row of the first matrix A and the jth column of the second matrix B, C must have as many rows as A and as many columns as B. Therefore, the shape of C is (m,q). Do you see why?

Notice that because of the restriction in the previous paragraph, matrix multiplication is not necessarily commutative. Concretely, A×B=B×A in general.

Remark. In Machine Learning applications, a good troubleshooting technique is checking that the dimensions (shapes) of the matrices are consistent with what is intended. This is especially true for matrix multiplication. For this reason, read the last paragraph closely to make sure you understand shapes after matrix multiplication.

This last operation of matrix multiplication will help us significantly in Machine Learning, as we will now see.

5.3Vectorization

Where do matrices even occur in Machine Learning? It turns out that we often put our data set into a matrix to make accessibility and computations easier. We put our parameters in matrices as well. Additionally, we can use matrix multiplication and matrix addition to compute the hypothesis function instead of manually doing the multiplications and then adding them together.

To see how and why we can do this, take the example from the Neural Network Hypothesis section.

Again, here is the image of the Neural Network structure:

Remember that we can calculate all of the ai(1)​s by the following: a1(1)​=σ(θ0(1)[1]​+θ1(1)[1]​x1​+θ2(1)[1]​x2​+θ3(1)[1]​x3​), a2(1)​=σ(θ0(1)[2]​+θ1(1)[2]​x1​+θ2(1)[2]​x2​+θ3(1)[2]​x3​), a3(1)​=σ(θ0(1)[3]​+θ1(1)[3]​x1​+θ2(1)[3]​x2​+θ3(1)[3]​x3​). Then, we can simply put the three ai(1)​s into a vector to get: ​a1(1)​a2(1)​a3(1)​​​=​σ(θ0(1)[1]​+θ1(1)[1]​x1​+θ2(1)[1]​x2​+θ3(1)[1]​x3​)σ(θ0(1)[2]​+θ1(1)[2]​x1​+θ2(1)[2]​x2​+θ3(1)[2]​x3​)σ(θ0(1)[3]​+θ1(1)[3]​x1​+θ2(1)[3]​x2​+θ3(1)[3]​x3​)​​. Make sure you understand this step. To simplify notation, we can redefine a sigmoid function to take in matrices as inputs rather than just scalars. We can say that σ(Z) is the sigmoid of each of the elements of Z for any matrix Z. This is nothing all to new. So, we can rewrite the above as: Z1​=​θ0(1)[1]​+θ1(1)[1]​x1​+θ2(1)[1]​x2​+θ3(1)[1]​x3​θ0(1)[2]​+θ1(1)[2]​x1​+θ2(1)[2]​x2​+θ3(1)[2]​x3​θ0(1)[3]​+θ1(1)[3]​x1​+θ2(1)[3]​x2​+θ3(1)[3]​x3​​​, and therefore, ​a1(1)​a2(1)​a3(1)​​​=σ(Z1​). Note that while Z1​ is a matrix, it is also a vector.

Now, let us focus on expressing Z1​ more simply. Firstly, we can take out the bias term from each of the entries of the vector. Specifically, Z1​=​θ0(1)[1]​θ0(1)[2]​θ0(1)[3]​​​+​θ1(1)[1]​x1​+θ2(1)[1]​x2​+θ3(1)[1]​x3​θ1(1)[2]​x1​+θ2(1)[2]​x2​+θ3(1)[2]​x3​θ1(1)[3]​x1​+θ2(1)[3]​x2​+θ3(1)[3]​x3​​​. Let B1​ be a matrix (and a vector) such that: B1​=​θ0(1)[1]​θ0(1)[2]​θ0(1)[3]​​​, so that Z1​=B1​+​θ1(1)[1]​x1​+θ2(1)[1]​x2​+θ3(1)[1]​x3​θ1(1)[2]​x1​+θ2(1)[2]​x2​+θ3(1)[2]​x3​θ1(1)[3]​x1​+θ2(1)[3]​x2​+θ3(1)[3]​x3​​​. Now, notice that the large term on the right can be expressed easily in terms of matrix multiplication: ​θ1(1)[1]​x1​+θ2(1)[1]​x2​+θ3(1)[1]​x3​θ1(1)[2]​x1​+θ2(1)[2]​x2​+θ3(1)[2]​x3​θ1(1)[3]​x1​+θ2(1)[3]​x2​+θ3(1)[3]​x3​​​=​θ1(1)[1]​θ1(1)[2]​θ1(1)[3]​​θ2(1)[1]​θ2(1)[2]​θ2(1)[3]​​θ3(1)[1]​θ3(1)[2]​θ3(1)[3]​​​×​x1​x2​x3​​​

Problem. Multiply the above out and confirm that both sides are indeed the same.

The factor on the right is just our input! Let this input matrix (also a vector) be X. Also, let the parameter matrix on the left be W1​. Then, ​θ1(1)[1]​x1​+θ2(1)[1]​x2​+θ3(1)[1]​x3​θ1(1)[2]​x1​+θ2(1)[2]​x2​+θ3(1)[2]​x3​θ1(1)[3]​x1​+θ2(1)[3]​x2​+θ3(1)[3]​x3​​​=​θ1(1)[1]​θ1(1)[2]​θ1(1)[3]​​θ2(1)[1]​θ2(1)[2]​θ2(1)[3]​​θ3(1)[1]​θ3(1)[2]​θ3(1)[3]​​​×​x1​x2​x3​​​=W1​×X. Substituting this back into the original equation for Z1​, we find Z1​=B1​+​θ1(1)[1]​x1​+θ2(1)[1]​x2​+θ3(1)[1]​x3​θ1(1)[2]​x1​+θ2(1)[2]​x2​+θ3(1)[2]​x3​θ1(1)[3]​x1​+θ2(1)[3]​x2​+θ3(1)[3]​x3​​​=B1​+W1​×X or Z1​=W1​×X+B1​. (Remember that matrix addition is commutative.) Finally, let A1​=​a1(1)​a2(1)​a3(1)​​​, which is what we wanted to find in the first place. Then, A1​=σ(Z1​)=σ(W1​×X+B1​). Make sure you understand this.

Now, we vectorize the process of finding the next layer, or the Output Layer. Recall that y1​^​=σ(θ0(2)[1]​+θ1(2)[1]​a1(1)​+θ2(2)[1]​a2(1)​+θ3(2)[1]​a3(1)​), y2​^​=σ(θ0(2)[2]​+θ1(2)[2]​a1(1)​+θ2(2)[2]​a2(1)​+θ3(2)[2]​a3(1)​). We can put this into matrices as well, just like last time: (y1​^​y2​^​​)=(σ(θ0(2)[1]​+θ1(2)[1]​a1(1)​+θ2(2)[1]​a2(1)​+θ3(2)[1]​a3(1)​)σ(θ0(2)[2]​+θ1(2)[2]​a1(1)​+θ2(2)[2]​a2(1)​+θ3(2)[2]​a3(1)​)​). Now, let Z2​=(θ0(2)[1]​+θ1(2)[1]​a1(1)​+θ2(2)[1]​a2(1)​+θ3(2)[1]​a3(1)​θ0(2)[2]​+θ1(2)[2]​a1(1)​+θ2(2)[2]​a2(1)​+θ3(2)[2]​a3(1)​​) so that (y1​^​y2​^​​)=σ(Z2​). Now, we find a more compact form for Z2​, like last time. We can separate the bias terms first: Z2​=(θ0(2)[1]​θ0(2)[2]​​)+(θ1(2)[1]​a1(1)​+θ2(2)[1]​a2(1)​+θ3(2)[1]​a3(1)​θ1(2)[2]​a1(1)​+θ2(2)[2]​a2(1)​+θ3(2)[2]​a3(1)​​). Now, let B2​=(θ0(2)[1]​θ0(2)[2]​​) so that Z2​=B2​+(θ1(2)[1]​a1(1)​+θ2(2)[1]​a2(1)​+θ3(2)[1]​a3(1)​θ1(2)[2]​a1(1)​+θ2(2)[2]​a2(1)​+θ3(2)[2]​a3(1)​​). The addend term on the right can be written more easily using matrix multiplication: (θ1(2)[1]​a1(1)​+θ2(2)[1]​a2(1)​+θ3(2)[1]​a3(1)​θ1(2)[2]​a1(1)​+θ2(2)[2]​a2(1)​+θ3(2)[2]​a3(1)​​)=(θ1(2)[1]​θ1(2)[2]​​θ2(2)[1]​θ2(2)[2]​​θ3(2)[1]​θ3(2)[2]​​)×​a1(1)​a2(1)​a3(1)​​​. But the product on the right is just A1​ from before! Also, we can let the factor on the left be W2​. So, (θ1(2)[1]​a1(1)​+θ2(2)[1]​a2(1)​+θ3(2)[1]​a3(1)​θ1(2)[2]​a1(1)​+θ2(2)[2]​a2(1)​+θ3(2)[2]​a3(1)​​)=W2​×A1​. Then, Z2​=B2​+(θ1(2)[1]​a1(1)​+θ2(2)[1]​a2(1)​+θ3(2)[1]​a3(1)​θ1(2)[2]​a1(1)​+θ2(2)[2]​a2(1)​+θ3(2)[2]​a3(1)​​)=B2​+W2​×A1​ or Z2​=W2​×A1​+B2​. Now, let A2​=(y1​^​y2​^​​). We then have A2​=σ(Z2​)=σ(W2​×A1​+B2​). We can substitute our earlier value for A1​ to get h(X)=A2​=σ(W2​×σ(W1​×X+B1​)+B2​), and this is our hypothesis function.

Problem. Make sure you understand this derivation of the hypothesis function.

Note that in this form, the hypothesis function is not specific to our problem; rather, the hypothesis function could take in inputs of any size and have any number of parameters and outputs.

If we added more layers, we would go through an almost identical process as we did above. In fact, the above hypothesis function looks similar to a composite function, and that is because it is!
